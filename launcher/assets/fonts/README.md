# Fonts

The launcher uses [Satoshi](https://www.fontshare.com/fonts/satoshi) by Indian Type Foundry.
Its licence (ITF Free Font License) allows apps to embed it, but it does not allow the font files in a public repository.

Download Satoshi from Fontshare and copy these three files into this folder before you build:

- `Satoshi-Regular.ttf`
- `Satoshi-Bold.ttf`
- `Satoshi-Black.ttf`

The volume dial's number uses [IBM Plex Mono](https://github.com/IBM/plex) SemiBold. It is under the SIL Open Font License, so `IBMPlexMono-SemiBold.ttf` and its licence, `IBMPlexMono-OFL.txt`, are already in this folder.
